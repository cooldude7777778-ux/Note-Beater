# Note Beater

![Note Beater](assets/banner.png)

Мобильная ритм-игра для Android в горизонтальной ориентации. Четыре дорожки, тяжёлая сложность, кубики-ноты летят в ритм трека **Escape Remix** (160 BPM, 885 нот).

- Нажатия по нотам без звука, слышен только трек.
- Оценки: Идеально, Отлично, Хорошо, Мимо. Множитель очков растёт до x4 вместе с комбо.
- Неоновая дорожка, пульс на каждый бит, частицы и волны при попадании.
- Калибровка задержки звука в меню (удобно для Bluetooth-наушников).
- Ранг по итогам: S, A, B, C, D.

## Запуск

1. Положите в одну папку `index.html`, `manifest.webmanifest`, папку `assets` и файл `09__Escape_Remix.mp3`.
2. Включите GitHub Pages (Settings, Pages, ветка `main`, корень) и откройте ссылку на телефоне.
3. В Chrome выберите «Добавить на главный экран», игра откроется на весь экран в горизонтальной ориентации.

Локально: `python -m http.server`, затем откройте `http://localhost:8000`. Если трека нет рядом с игрой, в меню появится кнопка «Выбрать mp3».

## Управление

Тап по дорожке на экране. На компьютере: D, F, J, K. Пауза: кнопка справа внизу или Esc.

## Как устроена карта нот

Темп трека определён анализом звука: ровно 160 BPM. Карта лежит в `index.html` строкой `CH`: один символ на шестнадцатую долю, цифра 0-f это битовая маска дорожек. Время ноты равно `OFF + индекс * 60/BPM/4`. Если ноты опережают или отстают, сдвиньте `OFF` или используйте калибровку в меню.

## Файлы

- `index.html` игра целиком (графика, стили, логика, карта нот)
- `manifest.webmanifest` установка на главный экран
- `assets/icon.svg`, `icon-192.png`, `icon-512.png`, `favicon-32.png` иконки
- `assets/banner.png` картинка 1280x640 для превью репозитория (Settings, Social preview)

## Права на музыку

Escape Remix принадлежит авторам (Jaroslav Beck, Tokyo Machine). Для публичного репозитория проверьте, можно ли выкладывать mp3, либо оставьте файл только у себя: игра предложит выбрать трек вручную.
